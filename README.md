# AI-Driven RAN Digital Twin for Traffic Prediction and Load Optimization

A Python-based simulation project exploring the use of Machine Learning for traffic prediction and load optimization in 5G Radio Access Networks.

## 🇬🇧 English

### About
I started this project to connect my experience in mobile network engineering with my interest in AI-driven network optimization. It implements a simplified RAN Digital Twin to simulate network traffic, monitor cell load, predict future traffic, and explore load balancing strategies.

### Key Features
- 24-hour synthetic traffic simulation for three RAN cells.
- Cell load monitoring and visualization.
- Traffic prediction using Linear Regression and Random Forest.
- Capacity-aware traffic redistribution.
- Performance comparison before and after optimization.

### Technologies
Python, Pandas, NumPy, Matplotlib, Scikit-learn.

### Machine Learning Results

| Metric | Linear Regression | Random Forest |
|---|---:|---:|
| MAE | 2.79 | 5.03 |
| RMSE | 3.25 | 5.64 |
| R² | 0.098 | -1.716 |

*Preliminary results based on a small synthetic dataset.*

### Future Work
- More realistic traffic modeling.
- Improved traffic prediction.
- Advanced RAN load balancing.
- Reinforcement Learning and O-RAN integration.

## 🇮🇷 فارسی

### درباره پروژه
این پروژه با هدف بررسی کاربرد یادگیری ماشین در پیش‌بینی ترافیک و بهینه‌سازی شبکه‌های رادیویی 5G آغاز شده است. هدف من ایجاد ارتباط بین تجربه کاری در شبکه‌های موبایل و علاقه پژوهشی‌ام به بهینه‌سازی هوشمند شبکه است.

در این پروژه یک نمونه ساده از Digital Twin شبکه RAN برای شبیه‌سازی ترافیک، پایش بار سلول‌ها، پیش‌بینی ترافیک و بررسی متعادل‌سازی بار پیاده‌سازی شده است.

### قابلیت‌ها
- شبیه‌سازی ۲۴ ساعته ترافیک سه سلول.
- پایش و نمایش بار شبکه.
- پیش‌بینی ترافیک با Linear Regression و Random Forest.
- توزیع مجدد ترافیک متناسب با ظرفیت سلول‌ها.
- مقایسه عملکرد شبکه قبل و بعد از بهینه‌سازی.

### ابزارها
Python، Pandas، NumPy، Matplotlib و Scikit-learn.

### توسعه‌های آینده
- واقع‌گرایانه‌تر کردن شبیه‌سازی ترافیک.
- بهبود مدل‌های پیش‌بینی.
- توسعه الگوریتم‌های پیشرفته Load Balancing.
- بررسی کاربرد Reinforcement Learning و O-RAN.
